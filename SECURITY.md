# Security Policy

## Supported Versions

MedMLOps-Lab is a portfolio and education project. Only the default branch is
actively maintained.

## Reporting A Vulnerability

Please report suspected vulnerabilities privately to the maintainer listed in
the repository metadata. Do not open public issues for secrets, credential
exposure, supply-chain concerns, or data-governance incidents.

## Sensitive Data

Do not submit protected health information, credentials, private endpoint URLs,
or proprietary datasets. The included Diabetes 130-US Hospitals dataset is used
because it is publicly available and redistributable under CC BY 4.0.
