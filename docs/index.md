# MedMLOps-Lab

MedMLOps-Lab is a production-shaped, CPU-only clinical risk-prediction platform
for demonstrating reproducible MLOps practices. It is not a notebook and not a
medical device.

Phase 1 establishes:

- Repository hygiene and contribution standards
- DVC-backed data ingestion
- Pandera data contracts
- Centralized deterministic execution defaults
- Documentation stubs for later governance work

See the repository README for the fastest setup path.
