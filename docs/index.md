# MedMLOps-Lab v1.0.0

MedMLOps-Lab is a production-shaped, CPU-only clinical risk-prediction
engineering reference with end-to-end data, model, clinical-rigor, serving,
monitoring, responsible-AI, governance, and release layers.

Its headline release gate rebuilds the Docker image without cache, reproduces
the complete DVC pipeline in a fresh container, and fails on any canonical
metric-hash divergence.

The project is a portfolio and educational demonstration. It is not a medical
device and must not be used for patient care.

Start with the [Quickstart](quickstart.md), then read
[Independent Reproduction](reproducibility.md) and
[CI/CD And Release Gates](ci-cd.md).
